# PX5 ZAR Helper™

Create compressed ZAR archives of game folders with PX5 ZAR Helper™ and ZArchive. Choose your output location and save space with game-dependent compression results.

**Created by M.E.H.™ — Founder of MEH Studio™**

## ✨ Features

- Create `.zar` archives from game folders.
- Choose where to save your archive instead of saving it beside the original game folder.
- Save archives to another drive when your game drive has limited free space.
- Simple folder selection and output filename workflow.

## 📖 How to Use

1. Launch PX5 ZAR Helper™.
2. Click **Choose Folder** and select the game folder you want to archive.
3. Choose the destination and filename for your `.zar` archive.
4. Allow the archiving process to finish.

## 📦 Compression and File Size

ZAR archives can significantly reduce game file sizes. Actual results depend on the contents of each game folder and the compression achieved.

### Example Results

- **Astro Bot:** 150 GB → 45 GB
- **Astro's Playroom:** 30 GB → 12 GB

These are example results observed during testing. Your results may vary depending on the game and its files.

## ⚙️ Requirement — ZArchive

PX5 ZAR Helper™ requires **ZArchive**, a separate open-source project created by Exzap.

ZArchive is **not included** with PX5 ZAR Helper™.

1. Download `zarchive.exe` from the official repository.
2. Place `zarchive.exe` beside the PX5 ZAR Helper™ launcher.
3. Launch PX5 ZAR Helper™ and select your game folder.

**Official ZArchive repository:**  
https://github.com/Exzap/ZArchive

ZArchive remains a separate project and is subject to its own license.
